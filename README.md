My entry for the Angry Judge short rant contest — a rant about the self-checkout machine that accused me of smuggling milk:

> I bought milk. One carton of milk. The self-checkout scanned it, weighed it, judged it, then froze and announced "unexpected item in the bagging area" like I had smuggled a live animal. A staff member strolled over, pressed one button, and the machine instantly forgave me — which means it knew all along. I stood there apologising to a robot for buying milk, and the robot won.
